## 1. 为什么做

团队一大就看不清结构：现在只在窗口标题上写「由 X 开启」（`WindowPane.tsx` 的 `openedByLabel`），抽屉里只有计划、任务、记录（`WorkbenchDrawer.tsx`）。谁是谁的上级、谁挂在哪个监管者下面、哪个在等 Tony，要一个个窗口去看。

参考：

- zf3d_agent：窗口之间的关系画成箭头，箭头按状态上色（审核中、待修改、已通过），小地图按状态上色。
- superset：侧边栏实时显示每个 agent 在干活、做完了还是需要处理；做完响提示音，需要处理时 Dock 图标有标记。

终端仍用分屏布局，不上无限画布（几十个实时终端放进可缩放画布，渲染、焦点和字体都会出问题）。另做一张团队图。

## 2. 团队视图

### 2.1 放在哪

抽屉加第四个标签「团队」，和计划、任务、记录并列。顶部栏加一个按钮直接打开。

### 2.2 画什么

- **节点**：每个窗口一个。显示标题、角色、运行时和模型、状态、内存。
- **实线**：上级关系（`openedBy` / `parentWindowId`）。管理者在最上面，往下一层层排。
- **虚线**：监管关系（`watcherWindowId`）。
- **节点颜色**按平台给的真实状态：

| 状态 | 颜色 |
|---|---|
| 忙 | 蓝，流动描边 |
| 空闲 | 灰 |
| 等批准、等拍板 | 橙 |
| 报了 blocked / failed | 红 |
| 报了 done | 绿 |
| 限流暂停（团队暂停） | 紫 |
| 休眠（[内存优化计划](./内存优化计划.md)） | 浅灰虚框 |
| 已退出 | 灰，删除线 |

- 点节点：切到它所在的标签并聚焦这个窗口。
- 悬停：显示最后一次汇报的摘要和时间。
- 画法：数据都在布局和主进程状态里（`ffpane_list_windows` 用的就是这份），树形自动排版，SVG 自己画，不引入图形库。

### 2.3 第一版不做

拖线改上级。上级关系决定汇报去向、监管挂靠和权限，随手一拖就改风险太大。以后要做，做成带确认的明确操作（「把执行 X 改挂到监管者 Y」）。

## 3. 状态提示

### 3.1 窗格和标签上

- 每个窗格标题栏一个状态点，颜色同 §2.2。
- 标签上：这个标签里有窗口在等 Tony（等批准、等拍板、报 blocked 给 Tony 自己开的窗口），标签名旁亮橙点。切走的标签也能看到。

### 3.2 窗口外（主窗口不在前台时）

只在**需要 Tony** 的事件上提醒，避免吵：

- 有窗口等批准；
- 有新的「待你拍板」；
- Tony 自己开的顶层窗口收到 blocked / failed；
- 窗口异常退出。

方式（设置里逐项开关）：

- 任务栏图标闪烁（Electron `BrowserWindow.flashFrame`），回到前台自动停；
- 任务栏角标显示待处理数（`setOverlayIcon`）；
- 提示音，默认关。

done 不闪烁，只在团队视图和标签上显示。

## 4. 改动

- 渲染端：抽屉「团队」标签和团队图组件；窗格状态点；标签状态点。
- 主进程：把「需要 Tony」的事件统一成一个计数（等批准、拍板、blocked、退出），推给渲染端；任务栏闪烁和角标在主进程做。
- 设置：工作台窗口一节加三个开关。
- 复用：状态来自现有的窗口状态、`api-error-tracker.ts`、拍板队列；内存来自 `terminal/manager.ts`。

## 5. 验收

1. 一个管理者、一个监管者、三个执行、一个检查：图上层次和连线正确，监管关系是虚线。
2. 执行等批准：节点变橙，所在标签亮橙点；主窗口不在前台时任务栏闪烁、角标 +1；处理后恢复。
3. 点节点能跳到别的标签里的窗口。
4. 改挂监管者（1.0.9 的自动改挂）后，虚线跟着变。
5. 10 个窗口时图仍清楚，不卡。
6. 提示开关关掉后不再闪烁、不响。

## 6. 风险

- 状态不准导致误提醒：只用平台的真实状态，不看终端文字（监管者说明里同样的原则）。
- 窗口多时图太挤：超过一屏可缩放、可折叠子树。
