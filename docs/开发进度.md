## 5. 关键技术事实备忘

- **pnpm 11**：allowBuilds 是「包名: true」映射（数组无效）；安装失败会自动改写 pnpm-workspace.yaml 插入提示行；.npmrc 只承载 auth/registry；`pnpm add` 失败时 package.json 变更会回滚——预装依赖后必须验证包真实存在（T0.5 首派终止的教训）
- **better-sqlite3 13.x**：Node-API 预编译，ABI 与运行时解耦，无需 electron-rebuild（R1 已解除）；trigram tokenizer 中文子串检索实测有效（R4 已解除），但 <3 码点查询恒不命中
- **T2.0 调研核心结论**：三家 CLI（Codex/Claude/Gemini）均实测存在"权限拒绝伪装成功"→ W2.7 自建权限层为强制路径；OpenCode 适配器必须走 Server(HTTP/SSE) 模式；Claude resume 绑定 cwd（Native Session ID 与 cwd 成对登记）；Codex 每轮一进程、file_change 无 diff（Run 前后 git 快照采集）；spawn 时必须清洗 OPENAI_* 等环境变量
- **工程约定**：exactOptionalPropertyTypes 全开（可选字段用条件展开）；品牌 ID 在 JSON 边界 as 收窄一次；录制 fixtures 目录已排除出 Biome 格式化（录制证据逐字节保真）；renderer 内禁止硬编码 CJK（check-i18n 扫描器把关），开发者日志一律英文
