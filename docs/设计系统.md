## 0. 本文档的地位与使用规则

Phase 3 的全部后续界面工单（W3.1b / W3.1c / W3.2a~W3.8b，共 17 个）以本文档为唯一视觉与交互基准。

```text
硬性规则：
1. 颜色只能来自 §3 的语义 token 生成的工具类（bg-surface / text-fg-muted / border-danger-border ...）。
   theme.css 里已用 `--color-*: initial` 清空 Tailwind 默认调色板：
   bg-red-500、text-gray-400 一类写法不会生成任何 CSS，会静默失效——这是刻意的护栏。
2. 尺寸只能来自 §4 的阶梯（间距为 4 的倍数、字号取 2xs~2xl、圆角取 sm/md/lg）。
   任意值语法（如 p-[7px]、text-[13.5px]）默认禁止；确有必要须在 PR 说明中给出理由。
3. 组件行为只能按 §5 的状态矩阵实现，交互只能按 §6 的时序与三态规范实现。
4. 需要新增 token 时不允许在页面工单里就地造：改 theme.css + 本文档，作为一次独立变更提出。
5. 所有 className 拼接经 `cn()`（§2.3），禁止字符串手工拼接与内联 style（除动态位置/尺寸计算）。
6. 所有 UI 文案进 `locales/*.json` 经 `useTranslation()` 引用（check-i18n 扫描器拦截硬编码 CJK）；
   开发者日志一律英文。
```

## 1. 设计原则

产品基调：**信息密度优先、简单实用、无装饰**。以下是可执行的具体化，不是口号。

### 1.1 信息密度优先

```text
允许 / 要求：
- 默认正文 13px、列表行高 28px（密集）或 32px（默认），一屏尽可能多的有效信息。
- 首屏即答：每个页面回答项目设计计划 §11 指定的那一个问题，无欢迎页、无引导层。
- 元信息（时间、路径、退出码、ID）用等宽字体 + text-xs + text-fg-muted，压缩占位但可读。
- 长列表虚拟化（万级记忆条目、十万级知识块），滚动不掉帧。
- 折叠优先于跳转：右侧栏、详情抽屉、可展开行，减少页面切换。

禁止：
- 用留白"呼吸感"换观感：段落间距超过 16px、卡片内边距超过 16px、页面外边距超过 24px。
- 一屏只放一张大卡片、一个大标题；标题字号 ≥ 24px 只允许出现在空态与错误页。
- 为对齐美观而截断有效信息（路径、命令、错误原文一律可完整查看，必要时可复制）。
```

### 1.2 无装饰

```text
明确禁止（产品红线，项目设计计划 §11 / §13）：
- 吉祥物、宠物、成就系统、等级/徽章激励、庆祝彩带、音效。
- 空状态插画、引导动画、视差滚动、入场动效、打字机式装饰动画
  （Agent 输出的流式渲染是数据行为，不算装饰，必须做）。
- 渐变背景、毛玻璃、彩色阴影、发光边框、大圆角（> 8px）、斜切装饰块。
- 装饰性 emoji（作为状态语义的图标用 lucide 线性图标，14px 或 16px）。
- 品牌色泛滥：primary 只用于"主操作 + 当前选中 + 进行中"，不用于装饰性点缀。

允许（属于功能而非装饰）：
- 深浅主题跟随系统并可手动切换（开发计划 §1.5 第 6 条明确列为实用功能）。
- 状态色、diff 增删底色、骨架屏脉冲、加载旋转图标、100~150ms 的颜色/透明度过渡。
- 图标 + 文字并列的状态徽章（图标不单独承载语义，色盲可读）。
```

### 1.3 一致性优先于局部最优

同类信息在七个页面里必须长得一样：状态徽章、时间格式、路径展示、diff、空态、错误态、危险确认，
各只有一种实现。发现两种写法时，改到与本文档一致，而不是新增第三种。

## 2. 主题基建

### 2.1 文件与职责

| 文件 | 职责 |
|---|---|
| `styles/theme.css` | 唯一的 token 定义处：`--ff-*` 双主题原始值、`@theme inline` 映射、静态阶梯、`@layer base` 基线 |
| `theme/resolve.ts` | 纯逻辑：偏好三态解析、实际主题解析（无 DOM 依赖，单测覆盖，见 `tests/theme.test.ts`） |
| `theme/dom.ts` | 浏览器副作用：localStorage 读写、`matchMedia` 探测与订阅、`html` 上应用 class 与 `color-scheme` |
| `theme/ThemeProvider.tsx` | React 上下文：三态偏好 + 跟随系统 + 持久化，全应用一个实例 |
| `theme/useTheme.ts` | `useTheme()` → `{ preference, resolvedTheme, setPreference }` |
| `theme/index.ts` | 对外出口：组件只从 `./theme` 导入，不引用内部文件 |
| `lib/cn.ts` | `cn()` = clsx + tailwind-merge |

Tailwind v4 无配置文件：扫描范围（`@source`）、dark 策略（`@custom-variant`）、token 全在 `theme.css` 内；
`electron.vite.config.ts` 的 renderer 段接入 `@tailwindcss/vite`。

### 2.2 主题解析规则

```text
偏好（用户可选三态）：system | light | dark，持久化在 localStorage["ffpane.ui-theme"]。
解析顺序（与 i18n 语言解析同一先例）：
  1. 已保存的合法值 —— 非法值/空值/未保存一律容错为 system，不抛异常
  2. system 时读 matchMedia("(prefers-color-scheme: dark)")
  3. 系统信号不可用时回退 light

应用方式：html.classList.toggle("dark") + html.style.colorScheme
  - class 驱动 CSS 里 `.dark` 的 token 覆盖与 Tailwind 的 dark: 变体
  - color-scheme 让原生控件（滚动条、原生 select 弹出层、表单控件）同步跟随

首帧无闪白：main.tsx 在挂载 React 前同步调用 applyThemeAtBoot()
（生产 CSP 禁内联脚本，无法在 index.html 里放引导脚本）。

持久化迁移路径：Phase 3 暂存 localStorage，与 i18n 语言选择同一先例；
后续接入全局 config.json（~/.aiworkbench/config.json，项目设计计划 §10.1）时，
唯一改动点是 theme/dom.ts 的读写（换成 IPC），resolve.ts 与 ThemeProvider 不动。
```

### 2.3 `cn()` 使用约定

```tsx
// 组件对外一律接受 className 并置于合并链末尾，使调用方可覆写
<div className={cn("rounded-md border border-border bg-surface p-3", className)} />
```

变体组合用 `class-variance-authority`（已预装）定义，禁止在 JSX 里写多层三元表达式拼类名。

## 3. 色板

### 3.1 命名与分层

token 原始值写在 `:root`（亮）/ `.dark`（暗）的 `--ff-*`，经 `@theme inline` 映射为 Tailwind 命名空间。
写代码时只用右侧的工具类名。

```text
层级关系：canvas（应用底色）< surface（卡片/面板）< surface-raised（浮层）
          surface-sunken 用于"凹陷"区域：代码块、输入框、表头、diff 行号槽
```

| Tailwind 名 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `canvas` | 应用底色（页面背景） | `#f6f7f9` | `#0e1116` |
| `surface` | 卡片、面板、侧栏、表格主体 | `#ffffff` | `#151920` |
| `surface-raised` | 对话框、下拉、popover、toast | `#ffffff` | `#1b2028` |
| `surface-sunken` | 代码块、输入框、表头、diff 行号槽 | `#eef0f3` | `#0a0d11` |
| `surface-hover` | 行/卡片 hover | `#f0f2f5` | `#1c222b` |
| `surface-active` | 行/卡片选中 | `#e4e8ee` | `#232a34` |
| `border` | 常规分隔线、卡片边框 | `#dcdfe4` | `#262d38` |
| `border-strong` | 可交互控件边界（输入框、次级按钮、开关轨道）、滚动条滑块 | `#828995` | `#626b7b` |
| `ring` | 焦点环 | `#2563eb` | `#5c9dff` |
| `overlay` | 对话框遮罩 | `rgb(15 18 23 / .45)` | `rgb(0 0 0 / .6)` |
| `fg` | 正文、标题 | `#14181d` | `#e7eaf0` |
| `fg-muted` | 次要文字、元信息、标签 | `#515a67` | `#a4adbb` |
| `fg-subtle` | 三级文字、占位符、禁用文字 | `#68717e` | `#8b94a3` |
| `fg-inverted` | 深色底上的反色文字（少用） | `#ffffff` | `#0b0f14` |

### 3.2 语义色四族

每族 6 个 token，用途固定：

| 后缀 | 用途 | 典型类名 |
|---|---|---|
| （无） | 实心填充（主操作/危险确认按钮、进度条） | `bg-primary` |
| `-hover` | 实心填充的 hover/active | `hover:bg-primary-hover` |
| `-fg` | 实心填充上的文字与图标 | `text-primary-fg` |
| `-surface` | 浅色底（提示条、徽章、选中态背景） | `bg-warning-surface` |
| `-border` | 浅色底配套边框 | `border-warning-border` |
| `-text` | 浅色底/页面底上的强调文字与链接 | `text-danger-text` |

| 族 | 语义 | 亮色（base / surface / text） | 暗色（base / surface / text） |
|---|---|---|---|
| `primary` | 主操作、当前选中、进行中 | `#2563eb` / `#e5edfd` / `#1a4fbe` | `#5c9dff` / `#16273f` / `#8fbcff` |
| `danger` | 破坏性操作、失败、越权拦截 | `#c9291d` / `#fdeae8` / `#a81f15` | `#f4776f` / `#3a1a18` / `#ff9c94` |
| `warning` | 需人工介入、阻塞、部分支持 | `#9a4a05` / `#fdf3e2` / `#7d3c04` | `#e8a33d` / `#3a2a10` / `#f0b95f` |
| `success` | 已接受、验证通过、连接成功 | `#06703f` / `#e6f5ee` / `#045a33` | `#3fca7f` / `#10301f` / `#6fdc9f` |

暗色主题的实心填充采用"亮底 + 深字"（`-fg` 为近黑），因为深底上白字达不到 4.5:1。

不设独立的 info 族：信息/进行中一律复用 `primary`。

### 3.3 任务状态色（7 态）

对应项目设计计划 §6.3 的状态机。每态三个 token：`status-<name>`（圆点/左边条）、
`status-<name>-surface`（徽章底）、`status-<name>-text`（徽章字）。

| 状态 | 语义 | 派生族 | 亮色 accent | 暗色 accent |
|---|---|---|---|---|
| `pending` | 已批准待执行 | 中性 | `#66707d` | `#8b94a3` |
| `running` | 执行中 | primary | `#2563eb` | `#5c9dff` |
| `blocked` | 等澄清/等权限审批 | warning | `#9a4a05` | `#e8a33d` |
| `failed` | 执行失败（可重试） | danger | `#c9291d` | `#f4776f` |
| `done` | Worker 声称完成且验证通过 | 独立青色 | `#0d6d64` | `#2dd4bf` |
| `accepted` | 用户确认接受（终态） | success | `#06703f` | `#3fca7f` |
| `cancelled` | 取消（终态） | 中性弱 | `#8a919c` | `#626b7b` |

`done` 与 `accepted` 必须不同色：`done ≠ accepted` 是产品的核心规则（"AI 说完成"≠"项目认为完成"）。
`cancelled` 与 `pending` 都是中性灰，靠**形状**区分：`cancelled` 徽章用 `border border-dashed`
且圆点为空心环，`pending` 为实心圆点。

### 3.4 能力三态（不新增 token）

适配器能力声明 `yes | partial | no`（`packages/adapters` 的 `CapabilitySupport`）复用现有族：

| 值 | 徽章类名 |
|---|---|
| `yes` | `bg-success-surface text-success-text border-success-border` |
| `partial` | `bg-warning-surface text-warning-text border-warning-border` |
| `no` | `bg-status-cancelled-surface text-status-cancelled-text border-border` |

`partial` 必须带 tooltip 说明"部分支持"的具体限制（如"有路径无 diff 正文"），不允许只给一个颜色。

### 3.5 diff 色

| Tailwind 名 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `diff-added-bg` | 新增行整行底色 | `#e6f5ea` | `#0f2a1b` |
| `diff-added-emphasis` | 新增行内词级高亮 | `#bfe8cc` | `#1c5133` |
| `diff-added-text` | `+` 标记与行号 | `#045a33` | `#6fdc9f` |
| `diff-removed-bg` | 删除行整行底色 | `#fdeceb` | `#341614` |
| `diff-removed-emphasis` | 删除行内词级高亮 | `#f8cdca` | `#6b2b27` |
| `diff-removed-text` | `-` 标记与行号 | `#a81f15` | `#ff9c94` |
| `diff-hunk-bg` / `diff-hunk-text` | `@@` 区块头 | `#eef0f3` / `#515a67` | `#171b22` / `#a4adbb` |

diff 正文一律 `text-fg` + `font-mono`（不染色），保证代码在增删底色上仍是最高对比度；
增删的语义由行首 `+ / -` 标记 + 底色**双重**承载（色盲可读）。

### 3.6 对比度实测

W3.1a 用脚本对全部 token 组合逐对计算 WCAG 2.1 对比度，**114 对全部通过**：

```text
文字类（阈值 4.5:1）：亮色 45 对，最低 4.61（fg-subtle on canvas）
                      暗色 45 对，最低 5.64（status-cancelled-text on status-cancelled-surface）
非文本类（阈值 3:1，边框/焦点环/状态圆点）：亮色 12 对最低 3.09，暗色 12 对最低 3.28
覆盖范围：正文/次要/三级文字 × 五种层级底色、四族实心填充的 -fg、四族 -text × 三种底、
          7 态徽章、diff 正文与增删底/词级高亮、border-strong 与 ring 对三种底色
```

新增或修改任何色值时，必须重跑同类校验并保持全绿；正文对比度 ≥ 4.5:1 是硬底线。

## 4. 尺度阶梯

### 4.1 间距（4px 基）

`--spacing: 0.25rem`，所有 `p-* / m-* / gap-* / size-*` 均为 4 的倍数。

| 步进 | 值 | 用途 |
|---|---|---|
| `1` | 4px | 图标与文字间隙、徽章内边距 |
| `1.5` | 6px | 徽章横向内边距（唯一允许的半步） |
| `2` | 8px | 紧凑控件内边距、行内元素间隙 |
| `3` | 12px | 卡片内边距（密集）、表单行间距 |
| `4` | 16px | 卡片内边距（默认）、区块间距 |
| `6` | 24px | 页面外边距、大区块间距（上限） |

禁止：`p-5`、`p-7`、`gap-10` 及以上，任意值间距。

### 4.2 字号（已整体下压一档，正文 13px）

`theme.css` 重定义了 Tailwind 的 `--text-*` 阶梯，**同名类的实际字号与 Tailwind 默认值不同**：

| 类名 | 字号 / 行高 | 用途 |
|---|---|---|
| `text-2xs` | 11px / 16px | 徽章、角标、表格密集元信息 |
| `text-xs` | 12px / 18px | 元信息、表头、时间、路径、快捷键提示 |
| `text-sm` | 13px / 20px | **默认正文**（body 已设为此值），控件文字、列表行 |
| `text-base` | 14px / 22px | 长文本正文：会话消息、计划正文、记忆条目详情 |
| `text-lg` | 16px / 24px | 页面标题、对话框标题 |
| `text-xl` | 20px / 28px | 少用：设置页大标题 |
| `text-2xl` | 24px / 32px | 仅空态/错误页的单行主标题 |

禁止 `text-3xl` 及以上。字重只用 `font-normal`（正文）、`font-medium`（强调/表头）、
`font-semibold`（标题）；禁止 `font-bold` 及以上，禁止 CJK 斜体。

### 4.3 等宽字体

`font-mono`（Cascadia Mono → Consolas → 系统等宽）**必须**用于：
文件路径、命令行、退出码、diff 正文、Session/Run/条目 ID、版本号、JSON 片段、快捷键键位。
搭配 `text-xs`（元信息）或 `text-sm`（代码块）。

### 4.4 圆角

| 类名 | 值 | 用途 |
|---|---|---|
| `rounded-sm` | 3px | 输入框、按钮、徽章、代码块 |
| `rounded-md` | 5px | 卡片、面板、下拉菜单 |
| `rounded-lg` | 8px | 对话框、命令面板（上限） |
| `rounded-full` | — | 仅状态圆点与头像占位 |

### 4.5 阴影（克制）

只有两个，且**只允许用于浮层**：

| 类名 | 用途 |
|---|---|
| `shadow-raised` | 下拉菜单、popover、tooltip、toast |
| `shadow-overlay` | 对话框、命令面板 |

禁止在卡片、按钮、输入框、表格、侧栏上使用阴影——层级靠 `surface` 色阶与 `border` 表达。

### 4.6 边框与动效

```text
边框：一律 1px（border）。@layer base 已把全局默认边框色设为 --ff-border，
      写 border 即得语义色；需要更强边界时显式 border-border-strong。
      分隔线用 border-b/border-t，不用 <hr>，不用 2px+ 粗线（tabs 的下划线除外）。

动效：只允许 colors / opacity / transform 三类过渡，时长 100ms（交互反馈）
      或 150ms（浮层进出），缓动用默认。禁止 layout 动画、禁止 > 150ms、
      禁止无限循环动画（骨架屏 animate-pulse 与加载图标 animate-spin 除外）。
      prefers-reduced-motion: reduce 时全局关闭过渡（@layer base 已处理）。
```

## 5. 组件规范

W3.1b 用预装的 radix primitives + cva 手写这些组件（不装 shadcn CLI）。下列类名串是实现基准。

### 5.1 按钮

**层级矩阵（每屏 primary ≤ 1 个）**

| 变体 | 用途 | 禁用场景 | 基准类名 |
|---|---|---|---|
| `primary` | 页面主操作（派发、批准、保存、导入） | 不用于取消/关闭/次要操作；同屏不出现两个 | `bg-primary text-primary-fg hover:bg-primary-hover` |
| `secondary` | 默认按钮、并列操作 | 不用于破坏性操作 | `border border-border-strong bg-surface text-fg hover:bg-surface-hover` |
| `ghost` | 工具栏、行内操作、图标按钮 | 不用于需要被发现的主操作 | `text-fg-muted hover:bg-surface-hover hover:text-fg` |
| `danger` | 破坏性操作的**最终确认**按钮 | 不用于列表行内直接触发（先二次确认） | `bg-danger text-danger-fg hover:bg-danger-hover` |
| `link` | 跳转到其他页面/外部 | 不用于会改数据的操作 | `text-primary-text underline-offset-2 hover:underline` |

**尺寸**

| 尺寸 | 高度 | 类名 | 用途 |
|---|---|---|---|
| `sm` | 24px | `h-6 px-2 text-xs gap-1` | 列表行内、表格单元格内 |
| `md`（默认） | 28px | `h-7 px-2.5 text-sm gap-1.5` | 绝大多数场合 |
| `lg` | 32px | `h-8 px-3 text-sm gap-1.5` | 对话框主操作、空态动作 |

图标按钮：`size-6`（sm）/ `size-7`（md），图标 14px（sm）/ 16px（md），必须有 `aria-label` 与 tooltip。

**状态矩阵（所有变体一致）**

| 状态 | 表现 |
|---|---|
| hover | 见各变体的 `hover:` 类；`transition-colors duration-100` |
| active | `active:translate-y-px`（唯一允许的位移动效）或 `-hover` 色再深一档 |
| focus-visible | 全局焦点环（`@layer base` 已给），禁止 `outline-none` 而不补 ring |
| disabled | `disabled:cursor-not-allowed disabled:opacity-55 disabled:pointer-events-none`；必须用 tooltip 说明"为什么不可用" |
| loading | 保持原尺寸（防跳动），文字前插 `Loader2` + `animate-spin`，`aria-busy="true"`，同时 disabled |

### 5.2 输入 / 文本域 / 选择器

```text
基准：h-7 w-full rounded-sm border border-border-strong bg-surface px-2 text-sm text-fg
      placeholder:text-fg-subtle
禁用：disabled:bg-surface-sunken disabled:text-fg-subtle disabled:cursor-not-allowed
错误：border-danger + 控件下方一行 text-xs text-danger-text 显示错误原文（不用 tooltip 藏错误）
只读：readOnly + bg-surface-sunken，路径/ID 类只读值必须可选中复制
搜索框：左侧 14px Search 图标（pl-7），右侧 Esc/清除按钮；聚焦快捷键见 §7
文本域：min-h-[计算行数]，会话输入框随内容增高，上限约 8 行后内部滚动

标签：控件上方或左侧，text-xs text-fg-muted；必填项在标签后加 text-danger-text 的星号；
      禁止只用 placeholder 当标签。
```

选择器优先用 radix `Select`（键盘可达 + 主题可控）；`> 20` 项时改用带搜索的 popover 列表。

### 5.3 卡片 / 面板

```text
基准：rounded-md border border-border bg-surface
内边距：p-3（密集列表卡片）或 p-4（详情面板）
可点击卡片：额外 hover:border-border-strong hover:bg-surface-hover cursor-pointer，
            且必须是 <button>/<a> 或带 role + 键盘可达
选中卡片：bg-surface-active + border-primary
禁止：阴影、渐变、内嵌大图、卡片套卡片超过两层
```

任务卡片（W3.6a）内容顺序固定：状态徽章 + 任务目标（`text-sm font-medium`，两行截断）→
`write_scope`（`font-mono text-xs text-fg-muted`，超出折叠为"+N"）→ 最新 Run 摘要 → 操作按钮组（`sm`）。

### 5.4 标签页

```text
基准（下划线式，radix Tabs）：
  容器：flex items-center gap-4 border-b border-border
  项：  h-8 border-b-2 border-transparent px-1 text-sm text-fg-muted
  选中：border-primary text-fg font-medium
  角标：紧随文字，text-2xs 徽章（如"待审核候选 (12)"）
禁止：胶囊式/卡片式 tab、图标-only tab、超过 6 个 tab（超过则改为侧边导航）
```

### 5.5 对话框（radix Dialog）

```text
遮罩：fixed inset-0 bg-overlay
内容：rounded-lg border border-border bg-surface-raised shadow-overlay p-4
      宽度 max-w-md（确认类）/ max-w-2xl（表单类）/ max-w-4xl（diff 预览类）
结构：标题 text-lg font-semibold → 说明 text-sm text-fg-muted → 主体 → 底部操作条
      （右对齐，取消在左、主操作在右，均为 lg 尺寸）
行为：Esc 关闭、点遮罩关闭（表单有未保存改动时先提示）、焦点进入后 trap、关闭后焦点还原
禁止：嵌套对话框；用对话框承载可以内联完成的编辑；无标题的对话框
```

**危险操作二次确认**（开发计划 §1.5 第 5 条）统一样式：

```text
标题：动作 + 对象（如"移除项目 foo？"）
说明：一句话讲清后果与不可逆范围（如"仅从工作台移除，不删除磁盘文件"）
       后果里涉及的数量/路径用 font-mono 强调
按钮：取消（secondary，默认焦点）| 确认（danger）
超危险（删除知识库来源、重建索引、清空习惯档案）：额外要求输入对象名称，
       输入不匹配则确认按钮保持 disabled
```

### 5.6 表格 / 列表行

```text
表头：sticky top-0 bg-surface-sunken text-xs font-medium text-fg-muted，行高 28px，
      可排序列整列可点 + 排序箭头 12px
行：  h-7（密集）/ h-8（默认），border-b border-border，
      hover:bg-surface-hover，选中 bg-surface-active + border-l-2 border-primary
单元格：px-2，数值右对齐，时间与路径 font-mono text-xs，超长中间省略（路径保留尾部文件名）
行内操作：默认隐藏、hover/focus 时显示（opacity-0 group-hover:opacity-100 + focus-visible 恒显），
          破坏性操作不放行内直接执行
禁止：斑马纹、竖向网格线、行高 < 24px、把关键操作藏进"更多"菜单
长列表：> 200 行必须虚拟化；分页只在服务端/数据库分页时使用
```

### 5.7 状态徽章

```text
基准：inline-flex items-center gap-1 rounded-sm border px-1.5 py-0.5 text-2xs font-medium
圆点：size-1.5 rounded-full bg-status-<state>（cancelled 用 size-1.5 rounded-full border 空心环）
颜色：bg-status-<state>-surface text-status-<state>-text border-transparent
      （cancelled 用 border-dashed border-border）
文案：全部走语言包 task.status.<state>；徽章必须带文字，禁止只有圆点
running：圆点加 animate-pulse（唯一允许的徽章动效）
```

其他徽章沿用同一骨架，只换色源：能力三态见 §3.4；权限摘要（只读/可写/可执行）用
`bg-surface-sunken text-fg-muted`，越权/危险项用 `danger` 族。

### 5.8 骨架屏

```text
基准：rounded-sm bg-surface-sunken animate-pulse，高度取被替代内容的行高
用法：形状必须仿真实布局（列表 = 3~5 条行骨架；详情 = 标题条 + 3 行文本条 + 操作条占位）
      同一容器内的骨架条宽度不要全等（如 w-3/4、w-1/2、w-full 交替），避免"进度条"错觉
使用场景：首次进入页面/切换数据源的首次加载
禁用场景：
  - 已有数据的刷新（用行内进度或按钮 loading，不要把已有内容替换成骨架）
  - 预期 < 100ms 的加载（直接渲染，不闪骨架）
  - 流式输出中的消息（用光标占位，不用骨架）
禁止：整屏居中大 spinner、骨架上叠加百分比文字
```

## 6. 交互规范

### 6.1 反馈时序（开发计划 §1.5 第 3 条）

| 耗时 | 表现 |
|---|---|
| < 100ms | 无加载态，直接出结果；按钮 hover/active 的视觉反馈必须在 100ms 内出现 |
| 100ms ~ 1s | 触发控件进入 loading（保持尺寸），其余界面保持可交互 |
| 1s ~ 10s | 骨架屏或确定/不确定进度条 + **取消按钮**；文案说明正在做什么 |
| > 10s（Run 执行等） | 转为后台任务：页面可离开，完成时 toast 通知 + 状态徽章更新 |

Agent 输出一律流式渲染（增量追加，不等整段返回）；长列表滚动位置在数据追加时保持不跳。

### 6.2 三态（开发计划 §1.5 第 2 条，每个数据视图都必须实现）

```text
加载中：骨架屏（§5.8）。
空态：  一句话说明 + 一个主操作按钮，居中于内容区，图标可选（16px，fg-subtle）。
        文案格式："<还没有什么>。<下一步动作>。" 例："这个项目还没有计划。让 Planner 出一版。"
        禁止插画、禁止"暂无数据"式无信息文案、禁止空态里放多个按钮。
错误态：显示**错误原文**（font-mono text-xs，可复制、可展开全文）+ 一句人类可读的概括
        + 重试按钮（primary，sm/md）；能定位到设置项的错误附"去设置"链接。
        禁止把错误吞掉只显示"出错了"，禁止用 toast 替代区块内错误态（toast 会消失）。
区分"空"与"错"：请求失败不显示空态，必须走错误态。
```

### 6.3 可撤销优先（开发计划 §1.5 第 5 条）

```text
普通操作（归档记忆、移除项目、拒绝候选、删除知识库文档）：
  立即执行 + sonner toast「已归档 xxx」+「撤销」动作按钮，停留 5s；不弹确认框。
不可撤销操作（重建索引、清空习惯档案、批准计划、接受任务）：走 §5.5 的二次确认。
乐观更新：UI 先改，失败时回滚并用错误 toast 说明原因（原文可展开）。
表单：有未保存改动时离开页面/关闭对话框要拦截提示。
```

### 6.4 焦点与键盘可达（开发计划 §1.5 第 4 条）

```text
焦点环：全局 :focus-visible = 2px ring + 1px offset（@layer base 已给）。
        禁止 outline-none；确需自定义必须同时给等效可见样式。
Tab 顺序 = DOM 顺序：不使用正 tabindex；不可聚焦元素不承载操作。
浮层：radix 自带 focus trap 与还原；Esc 一律关闭最上层浮层。
列表：上下方向键移动焦点，Enter 打开，Space 选中；单字母快捷键只在列表有焦点时生效，
      且在输入框/文本域内必须失效。
可发现性：所有快捷键必须能在命令面板（Ctrl+K）里搜到并显示键位；
          按钮 tooltip 右侧显示键位（font-mono text-2xs text-fg-subtle）。
```

### 6.5 其他

```text
时间：列表用相对时间（"3 分钟前"），hover 显示绝对时间（font-mono，本地时区）。
路径：显示相对项目根的路径，中间省略，完整值进 tooltip + 可复制。
数字：计数用千分位；字节用 KiB/MiB；退出码原样显示（font-mono，非 0 用 danger-text）。
复制：所有 ID / 路径 / 命令 / 错误原文提供复制按钮（ghost sm 图标按钮），复制后 toast 一行确认。
```
