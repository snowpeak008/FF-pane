## 3. 抽查发现

**未发现功能缺陷，未发现红线被绕开。** 以下如实登记，均不影响结论：

1. **（口径，不影响结论）`repair.ts:168` 兜底分支的 action 语义偏借用。** Worker 轮铸 Run 失败后连 `failTask` 落盘也失败时，action 记为 `"task-already-settled"`——但此时任务实际仍停在 running，与该枚举注释「任务已不是 running，未动任务」（`:68-69`）不符。行为无害（错误已进 issues、日志有 `could not fail task`，b 单不消费 action 字面量），但诊断者按枚举注释理解会误判现场。建议后续加一个 `task-stuck` 之类的如实取值或改注释。
