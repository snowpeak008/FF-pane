## 2. 实测

- **Claude 2.1.302**：开着 `--dangerously-skip-permissions` 时，PreToolUse hook 返回 `permissionDecision: "deny"` 仍然生效。让它用 Write 写项目外，被拦下，文件没写出去。
- **Claude 的命令行**：hook 看得到命令，但看不出脚本里再去写哪里。真正的系统级隔离要用 Claude 自带的 Windows 沙盒（`/sandbox install`，要管理员授权，建沙盒用户和网络过滤），可能影响 Unity / Blender，这次不做。
- **Codex 0.166**：`-s workspace-write` 在 Windows 上是系统级拦截。实测往项目外写返回「拒绝访问」，项目里照常写，`writable_roots` 里的目录能写。**沙盒里的命令连不上网**：`network_access=true` 和 `false` 实测一样（沙盒外正常），要等 Codex 还在开发的网络代理功能。

## 3. 已定的事（Tony 2026-11-07 交给我选）

1. **全部权限（YOLO）照样给，套上小沙盒。** 不弹确认、能跑命令、能联网都不变，只是不能写项目外。
   - Claude：仍是 `--dangerously-skip-permissions`，加一道 PreToolUse 检查。
   - Codex：不再用 `--dangerously-bypass-approvals-and-sandbox`，改成 `workspace-write` + 不审批（`network_access=true` 也传了，但 0.166 的 Windows 沙盒里命令仍连不上网，代价写进验收办法）。
2. **能写的地方：** 项目目录；系统临时目录；Claude 计划模式的 `~/.claude/plans`；Claude 自己记忆的那一个目录（只到记忆搬完为止，见 5）；Tony 在项目卡片「配置」里填的「项目外可写目录」。
3. **「项目外可写目录」只能 Tony 在界面上改。** 存在 FF-pane 自己的 `projects.json`（用户目录下的 `.aiworkbench`），不放进项目，AI 改不了。改了要重开窗口才生效。管理者再在说明里写「工程放项目外」，执行会被拦下，原因里会说「停下来报上级，由 Tony 加允许目录」。
4. **Claude 的命令行只拦常见写法：** `>`、`>>`、`tee`、`mkdir`、`touch`、`cp`、`mv`、`rm`、`Set-Content`、`Add-Content`、`Out-File`、`New-Item`、`Copy-Item`、`Move-Item`、`Remove-Item` 的目标路径。只看写的目标，读项目外（比如调用 `D:\…\blender.exe`）不拦。脚本里再写哪里，拦不住，说明里写明。
5. **Claude 自己的记忆：先搬后关（T11.8b）。** 现在项目里的重要决定都在 Claude 自己的记忆里（52 份），FF-pane 项目记忆是空的。先把没过期的整理成项目记忆候选，Tony 在记忆页点通过；过期的、和现在规矩冲突的（如「一任务一子代理」）列出来。之后对 FF-pane 窗口设 `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` 关掉，并去掉 2 里的记忆目录例外。原来的文件不删。

## 4. 代码

- 新纯函数模块 `mcp/write-guard.ts`：路径是否在允许的目录里（大小写不敏感，认 `C:\`、`C:/`、`/c/`、`~`）；从命令里找写的目标；给出拒绝原因。
- `mcp/workbench-hook.ts`：PreToolUse 只做这道检查，不上报主进程、不连管道。
- `hook-launch.ts`：Claude 的 `--settings` 加 PreToolUse（Write、Edit、MultiEdit、NotebookEdit、Bash、PowerShell）。
- `launch-cli.ts`：算出允许的目录，经环境变量 `FF_PANE_WRITE_ROOTS` 交给 hook；Codex 把「项目外可写目录」交给 `sandbox_workspace_write.writable_roots`。
- `packages/core` 权限表：Codex 的 YOLO 改成 `workspace-write`、`never`、`network_access=true`。
- `packages/storage` 注册表加 `outsideWriteDirs`；IPC `projects:set-outside-write-dirs`；项目卡片「配置」对话框里加一栏，一行一个目录。
