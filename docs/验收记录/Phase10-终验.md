## 必须修复

**保存布局和冷启动写回会丢掉窗口覆盖值与对话历史。**

`applyAuthNode`（`apps/desktop/src/main/workbench/auth-registry.ts`）按白名单重做窗口对象，没有抄这些字段：

- `modelOverride`、`effortOverride`（T10.12b 记在布局上的覆盖）
- `conversations`、`sessionUnidentified`（T10.15b 的历史和「编号未识别」）
- `routeMode`、`routeProviderName`、`routeModel`、`routeEffort`（T10.13 已经记过的显示字段）

两条写回都走它：

1. 冷启动 `workbench:get-layouts`：项目第一次进登记时 `restoreColdLayout`，然后 `saveProject`。
2. 平时 `workbench:save-layout`：先 `keepModelEffortOverrides` 把磁盘上的覆盖补回渲染端送来的窗口，接着 `syncLayout` 又用 `applyAuthNode` 剥掉，再 `saveProject`。渲染端每次改布局大约 400 毫秒后就会保存。

`workbench:launch-cli` 续接时从磁盘布局读覆盖，`noteLaunchRead` 交回的内存快照没有用上。管理者改强度时，主进程会先把覆盖写进磁盘；渲染端随后那次保存又把它写掉。窗口当时正忙、要等空闲再续接的，续接几乎一定发生在这次保存之后，启动参数里就没有新模型和强度。应用关掉再开，历史列表也空了。当前对话编号 `nativeSessionId` 还在，所以「续接当前」还能对上这一条，从历史里选做不到。

存储层 `parseWindow` 本身认得这些字段。丢发生在写回之前。

T10.13 把「连法 / 模型显示丢了，覆盖可以以后再抄」记成建议。当时还没有对话历史。现在同一处写回把 §9.9「重启 / 续接带上覆盖」和 §9.10「从本窗口历史里选一段」一起弄丢，而且弄丢的是忙时排队这条主路径，不再只是标题上的显示。要修的话：写回时把上面这些字段从原窗口抄回去。不要改选路和认领规则。

终验探针（临时目录，已删）对 `restoreColdLayout` 断言覆盖还在，结果是 `modelOverride` 变成 `undefined`。同文件里另外五条探针通过，见第 3 节。

## 2. 安全原则（§7.4）

| 原则 | 终验 |
|---|---|
| 子进程不经 shell | 工作台 CLI 先解析成直接可执行文件，解析不到就拒绝，不回退 `cmd.exe`。PTY 工厂按文件加参数数组启动，没有 `shell: true`。 |
| 密钥只走环境变量 | 启动前检查 argv 和临时文件不含密钥明文。自配置拒绝 `apiKey` 和 `extraEnv` 里的密钥字样。 |
| 窗口令牌不进 argv、日志、文件、IPC 载荷 | Claude 的 MCP 文件只写 `${FF_PANE_WINDOW_TOKEN}`。Codex 用 `env_vars` 转发。认领记号不是令牌。 |
| 控制通道只走本地命名管道 | Windows 地址是 `\\.\pipe\ff-pane-wb-<随机>`。请求凭令牌认窗口。 |
| 不往别的窗口 PTY 写 AI 正文 | 提醒仍走固定模板并消毒。改模型不往 PTY 写切换命令。 |
| 只在回合结束且没有未决权限时自动投递 | 空闲队列仍看阶段和未决权限。没有超时强写。 |
| 不用 `--dangerously-bypass-hook-trust` | 启动参数组装和角色启动测试都不含这个旗标。全放开用的是计划里的另一套权限旗标。 |
| 权限只能自上而下；续接管理者 / 全放开要确认 | 开子窗口按祖先封顶。冷读布局不授予管理权。续接确认还在。 |
| 不写用户 `~/.claude`、`~/.codex` | 本轮没有读写这两处。Codex notify 只覆盖本次进程，不读用户 notify。 |

## 【手动试用步骤】

下面按修好之后应该看到的效果写。第 4 步后半段和第 5 步里「关掉应用再开、历史还在、强度还在」这两处，**当前这个版本做不到**，就是上面的必须修复。其余步骤可以先试。

1. **默认配置。** 打开设置里的「配置」。第一次应有一张名字像「默认配置」的，Claude 和 Codex 都是本机登录。看不到档案、自定义角色、旧的默认权限预设。API 来源还在。
2. **只配一路，并绑到项目。** 新建一张配置，只填 Claude，Codex 留空。新建项目时可以不选配置（跟着默认）。建好后在项目卡片上把绑定改成这张只配 Claude 的。回到工作台，开 Codex 应被拦住，并说明这张配置没有 Codex。开 Claude 应能开，窗口上写出本机登录，不再让你选档案。
3. **并行多个 Codex 和各自的编号。** 把一个窗口设成管理者。让它在同一个项目目录里接连开几个 Codex 工作者。每个子窗口应出现自己的短编号，可以复制。不要五个停在同一个编号，也不要一直停在「正在识别」。
4. **改思考强度后自动续接。** 等一个工作者这一轮结束、没有权限框。让管理者把它的思考强度改高一档。工作者应自己重新打开，标题旁边的强度变成新的，你不用在它的终端里打字。若它当时还在忙，应先显示「待生效」，空闲后自己续接，强度仍是新的。把管理者自己或一个全放开窗口的强度改掉：应先问你确认，没点之前窗口不要自己重启。
