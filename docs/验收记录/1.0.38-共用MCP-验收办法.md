# 1.0.38 工作台 MCP 改成主进程里共用一个 —— 验收办法（T11.19 第二部分）

> 计划：[`docs/终端漏线程与共用MCP计划.md`](../终端漏线程与共用MCP计划.md) §3（调研结果 §3.4，Tony 定的 §3.5）。开发 2026-11-20，尚未验收。

## 前提

- 改的是主进程，开发模式下 FF-pane 会整个重启；开发时 Tony 已关掉 FF-pane。
- 重开后日志第一行是 `FF-pane 1.0.38 started`，紧接着有一行 `[wb-mcp-http] listening on http://127.0.0.1:<端口>/mcp`。日志在 `~/.aiworkbench/logs/main-日期.log`（UTC 时间）。
- 窗口要**新开或重启**才换成新接法：重开 FF-pane 后续接的窗口会重新生成配置，自然换上。

## 改了什么

- **新的 HTTP 服务**（`main/workbench/mcp-http.ts`）：主进程里一个，`http://127.0.0.1:<随机端口>/mcp`，只听本机回环。
  - `Host` 只认 `127.0.0.1:<端口>` / `localhost:<端口>`，带 `Origin` 的拒绝；
  - `Authorization: Bearer <窗口令牌>`，和控制通道同一套令牌，窗口关掉或重启后旧令牌作废，回 401「窗口令牌无效或已作废……请重启该窗口后再试」；
  - 协议处理复用 `mcp/protocol.ts`；工具调用交给控制通道同一段分发代码（`handlers.ts` 的 `onTool`），授权逻辑没有复制；超时照 stdio 小进程（等事件 = 等待时长 + 20 秒，重启类 90 秒，其余 20 秒，规则抽成 `workbenchToolCallTimeoutMs` 两边共用）；
  - 工具调用回 SSE，每 15 秒一行注释加一条进度通知（用请求里的 progressToken；没给就只发注释，见计划 §3.5）；
  - 服务起不来时日志记一行，全部窗口退回小进程。
- **接法表**（`main/workbench/mcp-transport.ts`）：Claude、Codex 走 HTTP；Grok、Cursor 继续小进程，表里写了它们的 HTTP 写法和「已确认能连上、能列出工具，令牌能从环境变量传；没测真正调工具和 9 分钟等待；没有账号，等以后补测再切」。`FF_PANE_MCP_TRANSPORT=stdio` 全部退回小进程。
- **开窗**（`launch-cli.ts`、`mcp-server-spec.ts`、`mcp-temp.ts`）：
  - Claude：`--mcp-config` 里工作台条目是 `{"type":"http","url":"…","headers":{"Authorization":"Bearer ${FF_PANE_WINDOW_TOKEN}"},"timeout":600000}`，仍然 `--strict-mcp-config`，文件里只有占位符；知识库、自配置这些 stdio 条目照旧；
  - Codex：`-c mcp_servers.ffpane-workbench.url="…"`、`bearer_token_env_var="FF_PANE_WINDOW_TOKEN"`、`tool_timeout_sec=600`，命令行里没有令牌。
- `workbench-mcp.js` 照旧打包，给退路和 Grok、Cursor 用。`config-mcp` 小进程没动（Grok、Cursor 窗口开了自配置时仍会多一个）。

## 验收步骤

1. **版本和服务**：日志里有 `FF-pane 1.0.38 started` 和 `[wb-mcp-http] listening on …`。
2. **小进程没了**：开 10 个 Claude / Codex 窗口，任务管理器「详细信息」里按命令行看（或 PowerShell：`Get-CimInstance Win32_Process -Filter "Name='electron.exe'" | ? CommandLine -like '*workbench-mcp.js*'`），没有 `workbench-mcp.js` 的 electron 进程。改之前 9 个窗口约 190MB。Grok、Cursor 窗口照旧每个一个。
3. **团队照常**：管理者开窗口、发消息、收汇报、被叫醒都照常；监管者在线等事件（`ffpane_wait_events`）挂满几分钟照常返回。
4. **重启窗口**：管理者用 `ffpane_restart_window` 重启执行窗口后，执行窗口照常能用工作台工具。
5. **退路**（可选）：设环境变量 `FF_PANE_MCP_TRANSPORT=stdio` 再启动，窗口又各有一个 `workbench-mcp.js` 小进程，功能照常。
