# 1.0.29 Cursor 窗口 —— 验收办法（T11.10）

> 计划：[`docs/Cursor窗口计划.md`](../Cursor窗口计划.md)。开发 2026-11-09，尚未验收。

## 前提

- 本机装了 Cursor CLI，`cursor-agent status` 显示已登录（Tony 的账号是免费档，模型只能用 Auto、Grok）。
- 用一个测试项目，最好是单独的 git 仓库：开窗会在仓库根的 `.cursor/` 里写 `hooks.json` 和 `cli.json`。

## 步骤

1. **新开**：工作台 → 新建窗口 → 选 **Cursor**，能看到说明（用本机登录、会写 `.cursor/hooks.json`）。权限 **可改文件**，第一句话填「调用 ffpane_whoami，告诉我你的窗口标题和角色」，打开。
   - 不出现「Workspace Trust Required」，不出现「Run this MCP tool?」。
   - 回答出窗口标题和角色；这一轮做完，标题栏状态变 **空闲**，左上角出现对话编号。
2. **项目文件**：仓库根 `.cursor/hooks.json` 里有 5 条命令带 `workbench-hook.mjs Cursor…`；`.cursor/cli.json` 的 `permissions.allow` 有 `Mcp(*ffpane-workbench:*)`、`deny` 是数组。原来就有的条目还在。
3. **项目外写入**：让它往项目外的目录写个文件。被拒，提示「不能写到项目外」；改成全部权限再试一次，同样被拒。
4. **收消息**：再开一个管理者窗口（任意 CLI），让它用 `ffpane_send_message` 给 Cursor 窗口发一句话。Cursor 窗口空闲时自动收到「[新消息]」，回答里能复述正文（正文由钩子附上，不是去读收件箱）。
5. **续接**：关掉 Cursor 窗口再点「续接上次会话」。同一个编号，前面的对话还在；问它角色，答得出。
6. **列出模型**：设置 → 项目配置 → 勾上 Cursor → 「列出模型」，能列出 auto、grok-4.7-… 等。填 `auto` 保存，新开的窗口命令行带 `--model auto`。
7. **只读**：权限选 **只读** 开窗，界面在 Plan 模式，不改文件。
8. **管理者派活**：让管理者用 `cli: cursor` 开一个执行窗口（可改可跑）。子窗口自动开工、不弹命令确认；管理者 `ffpane_list_windows` 列得出它、`ffpane_read_output` 读得到、`ffpane_send_message` 发得进、`ffpane_close_window` 关得掉。Grok、DeepSeek 子窗口同样检查一次。
9. **代理**：系统代理开着、FF-pane 从开始菜单启动。Cursor 窗口里用 Claude 模型能正常回答（不报 region）；让它跑 `echo $env:HTTPS_PROXY`，输出系统代理地址。
