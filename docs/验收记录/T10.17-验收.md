## 7. 给 Tony 的手动试用

先确认本机 PowerShell 里输入 `claude` 能打开。DeepSeek 不是另一条命令。软件不会替你登录，也不会替你买额度。

1. **设置 → 模型来源 → 新建 Provider**，选 **DeepSeek**。地址应已经是 `https://api.deepseek.com/anthropic`。密钥必填。保存。
2. **设置 → 配置**，编辑默认配置，勾上 **DeepSeek**。这一路没有「本机登录」。来源选刚才那个。模型手填。计划里的例子是 `deepseek-chat` 或 `deepseek-reasoner`；若窗口开得了但模型不认，改填 DeepSeek 文档里现在的名字，例如 `deepseek-flash`。思考强度可以不填。保存。
3. 打开一个项目，新建窗口，选 **DeepSeek**。应能看到一句：窗口里是 Claude 的界面，模型是 DeepSeek。点打开。窗口标题和种类都应是 DeepSeek，不是普通 Claude。
4. 再开一个普通 **Claude Code** 窗口。它仍走原来的 Claude 那一路，不应改去连 DeepSeek 的地址。
5. 到你自己的用户目录看 Claude 的配置。不应出现这次填写的密钥或 DeepSeek 地址被写进去。密钥只应留在这个窗口的进程里。
6. 把配置里的 DeepSeek 勾掉再保存。新建窗口选 DeepSeek，应不能点开，并提示这张配置没有 DeepSeek。已经开着的 DeepSeek 窗口点重启，也应被拒绝。用管理者开一个 DeepSeek 子窗口，同样应被拒绝。
7. 再勾上之后，管理者可以开 DeepSeek 子窗口。接着聊应带原来的编号。另起一段会换新编号。
