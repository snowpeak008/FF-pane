# 1.0.23（T11.2d）窗口按个数自动排：改动与验收办法

**日期：** 2026-11-07
**状态：** 已提交（2026-11-07，版本 1.0.23），尚未验收。
**计划：** [面板布局计划.md](../面板布局计划.md) §6。

## 1. 改动

- 一页最多 6 个窗口，按个数排满：横向 1 整屏、2 左右、3 三列、4 上 2 下 2、5 上 3 下 2、6 上 3 下 3；竖向（工作台高 > 宽）转 90°。
- 关掉一个，剩下的往前挤、重新排；整页关空就去掉这页。
- 窗口标题栏的两个分屏按钮合成一个「＋」：在这个窗口后面加一个。标签栏新增「在这页加一个窗口」（方块加号），加到末尾。最右的「＋」仍是新建页。这页满了都开新页。
- 快捷键：去掉 Ctrl+Shift+\（向右分屏）和 Ctrl+Shift+D（向下分屏）；Ctrl+Shift+N 改成在当前窗口后面加一个。
- 拖分隔线只改相邻的两条或两格，最小 10%；双击恢复均分；这页个数一变就恢复均分。拖的时候只改界面，松手存一次。
- 拖窗口：落到同页另一个窗口上对调；落到别的标签加到那页末尾（满了提示「这一页满了」）；落到「＋」开新页。没有空格子可落了。
- **终端不重建**：所有窗口画在同一层、按窗口 id 做 key，增删、对调、最大化、横竖切换时只挪位置。以前对调、最大化、横竖切换都会把终端整个重建（重读回放、重建显卡绘制）。最大化时别的窗口只是藏起来，尺寸不变。
- 存档格式不变；读 1.0.19–1.0.22 存的布局时，把中间的空格去掉、按原顺序往前挤。

## 3. 验收办法（dev 模式）

先关掉 FF-pane 再用 FF-pane.exe 打开。

| # | 做法 | 应该看到 |
|---|---|---|
| 1 | 用现在的布局打开 | 窗口都在、顺序对；原来中间空着的格子没了，后面的往前挤 |
| 2 | 新建页，开 1 个窗口 | 占满整个工作台 |
| 3 | 依次加到 2、3、4、5、6 个 | 左右 → 三列 → 2×2 → 上 3 下 2 → 上 3 下 3；第 7 个开新页 |
| 4 | 窗口上的「＋」 | 新窗口加在它后面 |
| 5 | 标签栏的方块加号 | 加到这一页末尾 |
| 6 | 5 个时关掉第 2 个 | 变成 2×2，剩下的往前挤 |
| 7 | 加窗口、关窗口、对调、最大化时看 Claude / Codex 窗口 | 只挪位置，内容不清空、不从头重画回放、不闪 |
| 8 | 拖分隔线、双击分隔线 | 只改挨着的两格或两条；双击恢复均分；再加一个窗口后恢复均分 |
| 9 | 把主窗口拉成竖长条 | 转过来排（2 个上下、5 个左 3 右 2）；拉回来恢复 |
| 10 | 管理者连开子窗口 | 先放管理者那页末尾，满了进团队页，不切页 |
| 11 | Ctrl+Shift+N | 在当前窗口后面加一个 |
