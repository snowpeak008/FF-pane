# Cursor 账号管理计划（T11.18）

> 状态：2026-11-14 Tony 提，只写计划，未改代码。§5 三条 Tony 当天都选了推荐做法（见 §5），当天开发完（1.0.36），待验收。
> Tony：想在软件里主动加 Cursor：登录本机的 Cursor CLI、换账号、选能用的模型，不用每次去 PowerShell 里 `cursor-agent login`。不然用户根本不知道这个软件还能用 Cursor。
> 调研版本：Cursor CLI `2026.11.05-86047df`（本机，已有新版 `2026.11.13-eacade1`）。只跑了只读命令（`--help`、`status`、`about`、`models`），没动登录状态。

## 1. 现在的样子

- Cursor 窗口（T11.10，1.0.29）能开，但**登录全靠用户自己在终端里跑 `cursor-agent login`**。软件里唯一的提示是新开窗口选 Cursor 时那句「用你在本机 cursor-agent login 登录的账号」。
- 没装 CLI、没登录、额度用完，都要等窗口开出来、在终端里报错才知道。
- 模型：项目配置（设置 → 模型 → 项目配置）里勾上 Cursor 这一路，才能「列出模型」并选一个；不勾就用 Cursor 自己的默认模型。设置里没有一个地方专门说「Cursor」。

## 2. 真机查到的事实

| 事 | 结论 |
|---|---|
| 账号状态 | `status --format json`：`isAuthenticated`、`userInfo.email / firstName / lastName`。不联网也能答（读本地凭据）。 |
| 档位、版本 | `about --format json`：`subscriptionTier`（本机是 `Free`）、`cliVersion`、`latestStatus`（`update_available`）、`latestVersion`、`model`（Cursor 自己记的默认模型）。 |
| 登录 | `login`：打印登录链接，默认用 PowerShell 打开浏览器；设了环境变量 `NO_OPEN_BROWSER` 就不开，只打印「Open a browser and navigate to this link: <链接>」。之后自己轮询，浏览器里登录完进程就以 0 退出，凭据已存好。标准输入不是终端时不出二维码。 |
| 凭据存哪 | Windows：`%APPDATA%\Cursor\auth.json`（`accessToken`、`refreshToken`）。账号信息（邮箱、团队）另记在 `~/.cursor/cli-config.json` 的 `authInfo`。 |
| 退出 | `logout`：清掉凭据。 |
| 模型 | `models`：每行 `<id> - <显示名>`，默认那个带 `(default)`。**列的是全部模型，不标这个账号能不能用**：免费档选了 composer 之类会在窗口里报 `Model unavailable on Free`。 |
| 团队 | `team list` / `team switch`：有团队的账号可以切团队，模型和设置跟着团队走。 |
| 更新 | `update`：更新到最新版。 |
| Cursor 自己的默认模型 | 本机 `cli-config.json` 里记的是 Claude Opus 5.5，但账号是免费档——不传 `--model` 开窗会用不了。 |

## 3. 做法

### 3.1 设置里加一节「Cursor」（设置 → 模型，放最上面）

一张状态卡，一眼看清能不能用：

```
Cursor                                                      [刷新]
●  已登录  donna@…  ·  免费档  ·  CLI 2026.11.05（有新版 2026.11.13 [更新]）
   [换账号]  [退出登录]

默认模型   [ Auto（默认） ▾ ]   [列出模型]
   免费档只能用 Auto 和少数模型；选了用不了的，窗口里会报「免费档用不了这个模型」。
```

- **未安装**：写「没找到 Cursor CLI」，给一个「安装」按钮（见 3.4）和官方说明链接。
- **未登录**：「登录」按钮（见 3.2）。
- **已登录**：邮箱、档位、版本；「换账号」「退出登录」；有新版时「更新」。
- 状态在打开这一节时取一次（`status` + `about`，各几百毫秒），不轮询。
- 凭据（令牌）只在主进程和 CLI 之间，**界面只拿得到邮箱、名字、档位**。

### 3.2 登录 / 换账号

1. 主进程用直启的办法跑 `login`（同 `listCursorModels`，环境加 `NO_OPEN_BROWSER=1`）。
2. 从输出里认出登录链接，弹一个小框：「在浏览器里登录 Cursor」[打开浏览器] [复制链接] [取消]。「打开浏览器」用系统默认浏览器（`shell.openExternal`），只放行 `https://` 开头、域名是 cursor.com 的链接。
3. 进程以 0 退出 → 框里显示「已登录 xxx」，状态卡刷新；非 0 退出或 10 分钟没完成 → 显示 CLI 的报错，可以重试。点取消就结束这个进程。
4. **换账号** = 先 `logout` 再走上面的登录。浏览器里如果还登着旧账号，要在 Cursor 网页上先退出或选另一个账号（框里写一句提示）。
5. 有 Cursor 窗口在跑时换账号 / 退出：先提示「开着的 N 个 Cursor 窗口还用旧账号，重开后才换」——CLI 启动时读凭据，跑着的进程不受影响，但令牌刷新时可能失败。

### 3.3 默认模型

- 设置里选的是 **FF-pane 的 Cursor 默认模型**：项目配置里 Cursor 这一路没填模型（或没勾这一路）时开窗就带 `--model <它>`。项目配置填了的照旧优先。
- **不改 Cursor 自己的 `cli-config.json`**（那是 Tony 在 Cursor 里的偏好，改了会影响他在终端里单独用 CLI）。
- 初值是 `auto`：免费档也能用，避免现在这种「Cursor 默认记的是 Opus、免费档开窗就报错」。
- 下拉列表来自 `models`；档位是免费时，列表上方写一句提醒（CLI 不告诉哪些能用，不瞎标）。

### 3.4 安装 / 更新

- **更新**：跑 `update`，框里显示输出，完了刷新状态。开着的 Cursor 窗口不受影响（CLI 按版本目录装，新窗口才用新版）。
- **安装**：官方命令是 PowerShell 执行 `irm 'https://cursor.com/install?win32=true' | iex`（从网上下脚本执行）。点「安装」先确认，再在一个看得见输出的框里跑；不静默装。

### 3.5 让人知道能用 Cursor

- 新开窗口选 Cursor 时，那句说明换成**当场的账号状态**：「已登录 xxx（免费档）· 模型 Auto」；没装 / 没登录时写明，并给「去登录」按钮（直接弹 3.2 的框，不用跳设置）。
- 没登录时「开窗」按钮不禁用（CLI 自己也会提示登录），但旁边标黄。
- 使用说明加一节「用 Cursor」：装、登录、换账号、选模型、免费档限制。

### 3.6 不做

- **同时存多个账号一键切换**：要把 `auth.json` 里的令牌另存、切换时写回去。刷新令牌会轮换，存下的那份过一阵就失效，切过去还是要重登；而且要替 CLI 管令牌。先不做，见 §5 第 1 条。
- 团队切换（`team switch`）：Tony 的账号没有团队，先不放；以后有需要再加一个下拉。
- 管理者的工作台工具不碰登录：登录要人在浏览器里点，AI 做不了，也不该做。

## 4. 风险

- CLI 改输出格式：登录链接认不出来时，框里把 CLI 原文整段显示，用户照样能复制链接；状态取不到时卡片显示「状态未知」和原文。
- `about` 要联网查版本：网络不通时最多等几秒，档位和版本显示「未知」，不影响登录状态那一行（`status` 不联网）。
- 换账号时浏览器还登着旧账号：Cursor 网页会直接用旧账号授权。框里提示先在网页上退出。

## 6. 验收

- 没装 CLI：设置里显示「没找到」，点安装能装上，装完状态变成「未登录」。
- 设置里点登录：浏览器打开 Cursor 登录页，登录完不用碰终端，状态卡显示邮箱和档位。
- 换账号、退出登录：状态卡跟着变；开着 Cursor 窗口时有提示。
- 默认模型选 Auto 后，新开 Cursor 窗口带 `--model auto`；项目配置里填了模型的照旧用项目的。
- 新开窗口选 Cursor：看得到账号和模型；没登录时能当场登录。
- 令牌不出主进程（界面的 IPC 里只有邮箱、名字、档位）。
- 单测：登录链接识别、`status` / `about` 输出解析、默认模型的优先级；e2e：假的 cursor-agent 走一遍登录、退出、列模型。
