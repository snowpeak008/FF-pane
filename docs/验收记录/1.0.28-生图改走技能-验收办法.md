# 1.0.28（T11.9 第 6 步）生图改走技能：改动与验收办法

**日期：** 2026-11-08
**状态：** 已提交（2026-11-08，版本 1.0.28），尚未验收。
**计划：** [技能计划.md](../技能计划.md) §5、§7 D4 / D5。

## 1. 改动

- 去掉设置 → 模型里的「生图」一块（先不生图 / Codex 订阅 / 中转站），去掉 `image-gen:*` 四个通道、主进程 `main/image-gen/` 出图代码、工作台工具 `ffpane_generate_image`，以及它专用的 5 分钟超时。
- **没动的**：`config.json` 里旧的 `imageGen` 设置和系统密钥库里的中转站密钥（Tony 定不删）。`@ff-pane/shared`、`@ff-pane/storage` 对这个字段的读写照旧，保存别的设置时不会把它丢掉；只是程序不再用它。
- `ffpane_open_canvas` 多返回 `rowId`（这张图在画板上的那一行）。工具说明里写明：用技能改完图后，新图连同原图的 `rowId`、`asNewVersion: true` 再调一次，就挂到原图那一行当新版本；新图已被目录监听收成单独一行时也会挪过去。计划里原来要加的 `ffpane_canvas_attach_version` 不加了。
- `base.md`：「生图用启用的技能，存进 `.ffpane/canvas/`，没有就问用户」。说明书 2047 字节，不超过 2KB。
- 使用说明：画板一节改成生图走项目里勾上的技能；设置分组里「模型」不再有生图。

## 3. 验收办法（dev 模式）

| # | 做法 | 应该看到 |
|---|---|---|
| 1 | 设置 → 模型 | 只有模型来源和配置，没有生图 |
| 2 | 项目勾了 codex-image-studio，开一个窗口，让它出一张图 | 图进画板，画板按钮待检查数加一 |
| 3 | 在画板上给这张图写一条修改要求，让窗口改图 | 窗口先读修改要求，改好的图挂在原图那一行，成为第二个版本，不另开一行 |
| 4 | 项目不勾任何生图技能，让窗口出图 | 窗口说出不了、来问你，不去找别的办法 |
| 5 | 打开 `~/.aiworkbench/config.json` | `imageGen` 那一段还在；改一下别的设置（比如窗口上限）后它也还在 |
