# 画板改图

用户说「改这张图」「按标记改」「继续修图」时才读这本手册。平时不用。

## 1. 先读要求

`ffpane_open_canvas` 打开画板，返回这张图的 `marks`（用户打的标记）和 `markedImage`（带标记的预览）。

- 模板里的 `{{标记}}`、`{{用户批注}}` 是用户的原话，照办，不要自己发挥。
- 图上的气泡、编号框是**标记**，不是要画的内容。改出来的图里不要出现气泡和编号。

## 2. 再生图

- 用项目里启用的生图技能，不要自己调接口。
- 保存路径必须在 `.ffpane/canvas/` 内；技能要求填写输出目录时填这个路径。
- 没有可用的生图技能：先问用户，不要自己找替代方案。

## 3. 存回画板

- 新图放进画板，交给用户检查；不要直接覆盖旧图。
- 用户明说「替换」时才替换，并且保留旧图到回收站。
- 用户要放进项目时，用 `ffpane_export_canvas_image`，路径写在项目目录里。

## 4. 交代给上级

只需一句：改了哪张图、按哪条标记改的、新图那张在画板上的编号。详细过程写进 `ffpane_write_brief`，不要塞进汇报正文。
