# 1.0.26（T11.9 第 1 步）设置页分组：改动与验收办法

**日期：** 2026-11-08
**状态：** 已提交（2026-11-08，版本 1.0.26），尚未验收。
**计划：** [技能计划.md](../技能计划.md) §6、§10 第 1 步。

## 1. 改动

- 设置页左边一列分四组，右边一次只显示一组：
  - **通用**：外观、语言
  - **工作台**：同时运行的窗口数、默认权限、角色说明
  - **模型**：模型来源、生图、配置（生图在 1.0.28 改走技能后去掉）
  - **工具**：知识库检索、自配置
- 记得上次打开的是哪一组（存在界面状态里，和侧栏收起一样）。旧版本留下的界面状态没有这一项，打开时是「通用」。
- 地址带 `?group=models` 这类参数可以直达某一组。以后项目卡片上的「技能」入口用这条。
- 各块自己的样子、按钮、保存方式都没改，只是换了地方放。
- 「技能」一组在 1.0.27 加。
- 使用说明里「设置 → …」的路径跟着改成带组名的。

## 2. 已验证

- 单测：新增 `settings-groups.test.ts`（组的顺序、地址里的组优先、上次那一组、坏值回到第一组、旧界面状态没有这一项）。全量 190 个文件、2826 条通过。
- biome、check-i18n、typecheck 通过。
- e2e：新增 `settings-groups.spec.ts`（一次只显示一组；切到项目页再回来还是上次那一组；`?group=` 直达）。原来打开设置页的 12 个 spec 改成直达各自那一组，避免「找不到某个按钮」在别的组里白白通过；这 12 个加新 spec 共 20 条，加上 workbench-cli 里改角色说明那一条，都通过。
- 截图看过：左边四组，选中的那组左边有色条、底色加深，右边只有这一组的内容。

## 3. 验收办法（dev 模式）

只改了界面，重新加载界面或重启 FF-pane 即可。

| # | 做法 | 应该看到 |
|---|---|---|
| 1 | 打开设置 | 左边四组：通用、工作台、模型、工具；右边是「通用」（第一次打开）的外观和语言 |
| 2 | 点「模型」 | 右边只有模型来源、生图、配置；外观、语言不在了 |
| 3 | 去项目页，再回设置 | 还是「模型」那一组 |
| 4 | 重启 FF-pane，再打开设置 | 还是上次那一组 |
| 5 | 在各组里改一项（比如窗口上限、某个配置） | 和以前一样能保存，提示照旧 |
