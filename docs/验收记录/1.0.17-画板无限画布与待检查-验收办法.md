## 2. 改动

### 数据（`board.json`，都是可选字段，旧文件照读）

- `versions[].by`：谁放进画板的（窗口编号和标题；目录监听收进来的记 `"dir"`）。
- `notes[路径].review`：检查状态 `pending` 待检查 / `ai-pass` / `ai-fail` / `seen`，加检查的窗口和理由。**没有这一项的图（1.0.17 以前就在的）算已看。**
- `placements[行]`：拖过的行的位置。

### 规则（纯函数，单测直接测）

- `shared/workbench/canvas-review.ts`：待检查和 AI 不通过算「待检查」，标了「不要」的不算；只有检查、监管者、管理者能 AI 检查；**放这张图进画板的窗口不能检查自己的图**；只能检查待检查的（查过的别人不能再改）。
- `shared/workbench/canvas-world.ts`：无限画布排版。按天分块，最新的一天在上、块里最新的在前；一行放几张跟着当天张数走（块大致 16:10，6–60 张），看全部时整个画板是一片而不是细长条；拖过的行留在原处，自动排的绕开；视口裁剪、按缩放选图（很小只画色块，放大换 1024 那档）、下一张、看全部、打开时的视口。

### 主进程

- 放图、目录收图时新图记成待检查并记下是谁放的（`canvas-files.ts`）。出图工具和交图工具把窗口传进来。
- `canvas-library.ts`：`setCanvasReview`（Tony 已看 / 我再看看）、`aiReviewCanvasImage`（AI 检查，读改在同一把锁里）、`placeCanvasRow`（拖动位置）。
- 新工具 **`ffpane_canvas_review`**（`imagePath`、`pass`、`reason`，都必填），放进只读档也能用的工具里（只写 `.ffpane` 下的画板文件）。检查说明书加了一句。
- 待检查数：画板一改，300ms 合并一次重算，推 `workbench:canvas-pending`；界面新增 `workbench:get-canvas-pending` 取初值。取代 1.0.14 临时的「新图 N」。
- `ffpane-canvas://` 加 1024 一档（`size=large`）。

### 界面

- `CanvasWorld.tsx`（新）：无限画布。滚轮缩放、拖空白平移、拖卡片挪整行（松手存位置）、单击选中、双击看大图；只画看得见的行；缩得很小只画色块（黄待检查、红 AI 不通过、灰不要）；放大换 1024 图盖在缩略图上；日期标签画在屏幕坐标里，缩到看全部也认得出。卡片：待检查右上黄点、AI 通过绿字、AI 不通过红字和红框、「不要」和删图申请的角标。
- `WorkbenchCanvasPanel.tsx`：顶上「看全部」「下一张待检查（N）」「只看待检查」、按文件名找、回收站；下面一条选中条一直占着位置（没选时是提示，选中时画布不会被挤得跳一下）：文件名、路径、检查状态和理由、导出位置、删图申请，按钮「看大图」「已看 / 我再看看」「标为不要」「删除（进回收站）」「从画板移除」「回到自动排」。
- 大图（`CanvasViewer.tsx`，原 Viewer 原样挪出来）：上面「← 上一张」「下一张 →」（键盘左右键）、「已看 / 我再看看」「标为不要」「关闭大图（Esc）」。从待检查的图打开时上一张 / 下一张只在待检查里走。**打开大图看过就算已看。** Esc 先关大图，再按一次关画板。
- 画板整屏层不透明（`bg-surface-sunken`），和后面的终端分得开（Tony 2026-10-27 认可）。
- 顺手：画板和大图里原来用的 `neutral-*`、`white` 颜色主题里没有，一直没生效（标签条、气泡底色是透明的）；换成主题里的颜色。
- 画板按钮：「画板 · 待检查 N」。

## 4. 验收办法（《海上生存日记》真项目，dev 模式）

先关掉 FF-pane 再用 FF-pane.exe 打开（主进程改了）。

| # | 做法 | 应该看到 |
|---|---|---|
| 1 | 打开画板 | 最新一天的图铺满一屏；「看全部」看到整个画板，每天一块、标着日期；滚轮放大缩小、拖动都顺 |
| 2 | 让执行窗口出一张图 | 不弹画板；按钮「画板 · 待检查 1」；打开后那张图右上有黄点 |
| 3 | 开一个检查窗口，让它检查这张图 | 它调 `ffpane_canvas_review`；通过的话黄点没了、显示「AI 通过」，按钮数字减一；不通过的话红框、选中能看到理由 |
| 4 | 让出图的那个执行窗口自己检查自己的图 | 被拒绝，说明不能自己查 |
| 5 | 选一张待检查的图双击看大图，按 → 看下一张 | 看过的都算已看；Esc 关大图，再按 Esc 关画板 |
| 6 | 拖一张图到别处，关掉画板再开 | 还在拖到的位置；选中点「回到自动排」回去 |
| 7 | 1.0.17 以前就在画板上的图 | 都算已看，不计入待检查 |
